# AI Happy Entry: Gentle Watering Robot

A pure Python (standard library only) procedural illustration depicting a tiny round robot watering a young sunflower sprout at golden hour with a soft rainbow overhead.

## Running

```bash
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

## Details
- Canvas: 1024x1024 RGBA PNG
- Zero external dependencies (uses standard library `struct`, `zlib`, `math`, `os`).
- Fully deterministic: identical byte output across runs.
